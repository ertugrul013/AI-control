# Changelog

All notable changes to this project are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-11

### Added

- AI register with search, filters, sorting, CSV import and export, and a quick-add catalogue.
- Risk classification questionnaire with live tier preview, "check your answers", rationale with AI Act references, generated actions and assessment diff.
- Policy wizard (eight questions), Markdown editor, versions, PDF and Markdown export, acknowledgement by all users.
- AI literacy: three training modules in Dutch and English with a quiz, assignment per audience or user, and a to-do list for employees.
- Dashboard with the risk strip, items that need attention, coverage, department by tier, upcoming reviews and the AI Act countdown.
- Audit log of every change, full JSON and CSV export, management report as PDF.
- Roles (Admin, Editor, Viewer, Employee), email and password login, optional OIDC.
- Dutch and English interface, light and dark mode.
- Docker Compose setup with automatic migrations and demo data.
